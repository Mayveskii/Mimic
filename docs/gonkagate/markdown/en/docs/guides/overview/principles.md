# Principles

OpenAI-compatible API principles for Gonka Network access, USD billing, model IDs, plugins, and production integration choices.

GonkaGate makes Gonka Network usable like a normal API product.

## Why GonkaGate exists

The goal is simple: OpenAI-compatible access, prepaid USD billing, and clear costs without pushing wallets and token operations into the normal developer workflow.

## Core principles

- **Gonka Network, billed in USD.** Use Gonka Network through a prepaid USD balance.
- **OpenAI-compatible by default.** The integration path should feel familiar and low-friction.
- **No crypto required.** End users should not need wallets, signing flows, or token handling.
- **Transparent cost structure.** Show network cost, platform fee, and total cost separately.
- **Dedicated gateway, not an aggregator.** GonkaGate is a gateway to Gonka Network, not a multi-provider router.
- **Evidence over hype.** Prefer clear methodology and bounded claims over sweeping promises.

## What GonkaGate is not

GonkaGate is not:

- a provider aggregator
- a hosted inference fleet
- a crypto wallet or exchange
- the Gonka Network itself
- an official operator of Gonka Network
